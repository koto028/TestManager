# タスクボード プロトタイプ（認識合わせ用）

画面設計書 [SC-001](../../docs/画面設計.md) に基づく **静的モック** です。  
API・MySQL は使わず、ブラウザだけで画面イメージを確認できます。

## 開き方

1. エクスプローラーで `trello-app/prototype/index.html` をダブルクリック  
2. または Cursor で `index.html` を右クリック → **Reveal in File Explorer** → ブラウザで開く  

サーバー起動は **不要** です。

## 本番アプリとの違い

| 項目 | プロトタイプ | 本番（`trello-app/`） |
| ---- | ------------ | --------------------- |
| データ保存 | メモリのみ（F5 で初期状態に戻る） | MySQL + REST API |
| 起動 | `file://` で OK | `http://localhost:3000` 必須 |
| 目的 | 見た目・UI 状態の認識合わせ | 実装・テスト |

## 画面設計との対応

| 設計書 | プロトタイプ |
| ------ | ------------ |
| SC-001 タスクボード | `index.html` 1 ページ |
| AREA-02 ヘッダー | `header.board-header` |
| AREA-03 ボード | `main#board.board` |
| AREA-04 リスト列 | `section.list` × 3 |
| AREA-05 カード一覧 | `.list__cards` > `.card` |
| AREA-06 追加 UI | `.add-card` |
| ST-01 通常 | 「＋ カードを追加」ボタン |
| ST-02 入力中 | textarea + 追加 / キャンセル |

## 初期表示データ

| リスト | カード |
| ------ | ------ |
| やること | はじめてのタスク、レポート提出 |
| 進行中 | API 設計を読む（**追加フォームを ST-02 で表示**） |
| 完了 | 環境構築 |

## 操作（デモ）

- **＋ カードを追加** … 入力フォームを表示（ST-01 → ST-02）
- **追加** … カードを追加（空白は不可）
- **キャンセル** … フォームを閉じる
- **×** … カードを削除

## 認識合わせチェックリスト

- [ ] ヘッダーに「マイタスクボード」と MySQL 補足がある
- [ ] 3 リストが横並び（やること / 進行中 / 完了）
- [ ] カードに × ボタンがある
- [ ] ST-01（ボタンのみ）と ST-02（入力フォーム）が確認できる
- [ ] PC 幅（1024px 以上）で見やすい

## ファイル構成

```
prototype/
├── index.html   … 骨組み
├── mock.css     … 見た目（本番 style.css と同等クラス）
├── mock.js      … 最小インタラクション
└── README.md    … 本ファイル
```

## 本番への反映

プロトタイプで OK が出たら、`mock.css` の差分を `../style.css` に取り込み、  
HTML 構造・クラス名は `../app.js` の `render()` と揃えます。

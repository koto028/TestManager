# シンプルタスクボード（Trello風）

初心者向けの Phase 1 実装です。

## 機能

- リスト3列（やること / 進行中 / 完了）
- カードの追加・削除
- ブラウザの localStorage に自動保存

## 使い方

1. `index.html` をダブルクリックするか、ブラウザにドラッグ＆ドロップ
2. 各リストの「＋ カードを追加」からタスクを登録
3. カード右の × で削除

## ファイル構成

| ファイル     | 役割           |
| ------------ | -------------- |
| `index.html` | 画面の骨組み   |
| `style.css`  | 見た目         |
| `app.js`     | 追加・削除・保存 |

## データのリセット

ブラウザの開発者ツール（F12）→ Application → Local Storage から `trello-app-data` を削除すると、初期状態に戻ります。

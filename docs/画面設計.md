## 2. 画面構成（SC-001）

```
┌─────────────────────────────────────────────────────────┐
│  ヘッダー：システム名「マイタスクボード」               │
│           補足：MySQL に保存                             │
├─────────────────────────────────────────────────────────┤
│  ┌──────────┐  ┌──────────┐  ┌──────────┐              │
│  │ やること  │  │ 進行中    │  │ 完了      │              │
│  │ [カード]  │  │          │  │          │              │
│  │＋カード追加│  │＋カード追加│  │＋カード追加│              │
```

## 3. 画面要素

| 要素 | 種類 | 説明 | 関連 FR |
| ---- | ---- | ---- | ------- |
| リストタイトル | テキスト | やること / 進行中 / 完了 | FR-002 |
| カード | テキスト | タスク名を表示 | FR-003 |
| 削除ボタン（×） | ボタン | カードを削除 | FR-012 |
| カード追加ボタン | ボタン | 入力フォームを表示 | FR-010 |
| 入力欄 | textarea | 新規カードのタイトル | FR-010 |
| 追加ボタン | ボタン | 入力内容でカードを作成 | FR-010 |
| キャンセルボタン | ボタン | 入力を破棄しフォームを閉じる | FR-013 |

---

## 4. UI 状態（カード追加エリア）

| 状態 ID | 名称 | 表示内容 |
| ------- | ---- | -------- |
| ST-01 | 通常 | 「＋ カードを追加」ボタンのみ |
| ST-02 | 入力中 | textarea + 「追加」「キャンセル」 |

詳細な遷移は [基本設計.md](./基本設計.md) を参照。

---

## 1. 選定方針

| 方針 | 内容 |
| ---- | ---- |
| 学習目的 | Web 3 層構成・ER 図・REST API を体験 |
| シンプルさ | フレームワーク最小限、スクール課題で完遂可能な範囲 |
| スコープ | シングルユーザー。認証・マルチテナントは対象外 |

---

## 2. 技術スタック

| レイヤ | 選定 | 選定理由 |
| ------ | ---- | -------- |
| UI | HTML5 + CSS3 | Web 標準。既存 Phase 1 を継続 |
| フロント | JavaScript（Vanilla） | fetch で API 呼び出し。フレームワーク学習は別途 |
| API | Node.js + Express | JS で統一。REST API を実装しやすい |
| DB | MySQL 8.x | ER 図・SQL 学習。RDBMS として一般的 |
| DB ドライバ | mysql2 | Promise 対応 |
| 設定 | dotenv + `.env` | DB 接続情報をコードから分離 |

---

## 3. アーキテクチャ

```
[ブラウザ app.js] → fetch → [Express server.js] → SQL → [MySQL]
```

| ディレクトリ | 役割 |
| ------------ | ---- |
| `trello-app/` | フロント（HTML / CSS / JS） |
| `trello-app/server/` | API サーバー |
| `trello-app/server/db/` | DDL / ER 図 |

---

## 4. 採用しなかった技術

| 候補 | 不採用理由 |
| ---- | ---------- |
| localStorage のみ | DB 学習・永続運用の目的に合わない |
| React / Vue | 演習範囲外。素の JS で十分 |
| SQLite | 有効だが本課題では MySQL で ER/SQL を学ぶ |
| PHP + MySQL | フロントが JS のため Node で統一 |
| ORM（Prisma 等） | 生 SQL で DB 理解を優先 |
| JWT / セッション | マルチユーザー非対応のため不要 |

---

## 5. 実行環境

| 項目 | 要件 |
| ---- | ---- |
| Node.js | LTS 推奨 |
| MySQL | 8.x |
| ブラウザ | Chrome / Edge 最新版 |
| 起動 | `cd trello-app/server && npm start` |
| アクセス | `http://localhost:3000/index.html` |
